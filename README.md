# BLIND//SPOT

マーダーミステリー「uzu」と行き来する、一人用シナリオの **Web 側（ハッキング画面）** の試作です。
▶ **遊ぶ**：https://xnitokax.github.io/blind-spot/ （回線コードは下の「回線コード」の表にあります）

いまは **体験版** として公開しています（練習と任務1）。任務2以降のデータは別のファイル（`docs/scenario.more.js`）に分けてあり、タイトル画面で `connect nitoka` と打つと開きます。

設定は [設定メモ.md](設定メモ.md) が正です。未定のところは仮の内容で埋めて、最後まで筋が通るようにしています。
（`src/scenario.js` で「（仮）」を検索すると、あとで決めるところが見つかります）

## 遊び方

1. uzu 側で、師匠から **回線コード** を受け取る
2. Web 画面を開いて「CLICK TO CONNECT」を押す（ここから音が出る）
3. 初めてのときは、師匠に呼び名を聞かれる。`handle 名前` と打ち、確認に `y` で答える（コマンド入力のチュートリアルを兼ねる）
   決めた名前はプロンプト（`anonymous@safehouse:~$`）や師匠のセリフ、任務3の「予測ファイル　対象：〇〇」に使われる。2回目からは「おかえり」で始まる
4. 呼び名を決めると、師匠が「肩慣らしに練習していった方がいいぞ」と `connect training` を軽く勧める（くわしい案内は uzu 側で師匠がする）（チュートリアル。何回でもやり直せる。終えるまでは、タイトル画面の NEXT 欄に光るボタンで出る）
   師匠の練習用サーバーで、画面の見方（説明している部分が黄色の枠で光る）→ `ssh` / `help` / `back` → NEXT 欄の使い方を教わる。最後は師匠が昔つくったレトロ RPG（王城 → ダンジョン → 魔王城）で遊んで、エンド（4つ。この端末で見たものを記録）を見たら、師匠が笑いながら戻ってきて「じゃあ、行くぞ！」で終わる
5. `connect 回線コード` と打つ（`?line=回線コード` 付きの URL で開いた場合は、練習を飛ばして自動で打たれる）
6. 師匠が回線をつなぐ演出のあと、任務が始まる
7. 任務が終わると回線が切れる → uzu に戻って師匠に報告する

| コマンド | 使いどころ |
|---|---|
| `handle <名前>` | タイトル画面で、呼び名を決める・変える |
| `connect <回線コード>` | タイトル画面で、師匠から受け取った回線につなぐ |
| `ssh <名前>` | 接続先へ移動する |
| `back` | ひとつ前の場所へ戻る |
| `ls` | 今いる場所の行き先の一覧を、もう一度出す |
| `help` | 使えるコマンドの一覧 |
| `search <言葉>` | 日報・人事DB・伝票・変更ログなどを検索する。**上位3件しか表示されない**。スペース区切りで条件を重ねられる |
| `cd <フォルダ名>` | ファイルサーバーでフォルダを移動する |
| `return` | 調べ終わったら（任務1・2）、成果を持って帰る（任務を終える）。NEXT 欄の一番左に出る。早すぎると師匠に止められる |

パスワードやコードは、全角・半角、大文字・小文字を区別しません（全角の「！」で打っても通ります）。
検索は、さらにひらがな・カタカナと長音（ー）のあるなしも区別しません（「ゆーざーID」「ユーザID」でも見つかります）。「userid」「password」のような言いかえにも対応しています。
演出の途中は、画面を素早く3回クリック（または Enter を3回）すると早送りできます（1回だけでは飛ばないようにしています）。右上の SOUND で音を全部、BGM で音楽だけを消せます。

## 演出

- **音**：Web Audio でその場で合成しています（音声ファイルなし）。ピコピコした音は使わず、低音・ノイズ・残響で映画の UI のような質感にしています
- **BGM**：相棒の師匠が「いい音楽かけといてやるよ」と流す、作業に集中できる落ち着いたロー・ファイ寄りの曲。これもその場で演奏しています。メロディは毎回その場で作るので、同じくり返しにならず、長く聞いても疲れにくい。ラジオのように開いて始まり、師匠がしゃべる間は少し下がる。任務3の警報でテープのように止まり、師匠が回線を奪い返すと戻ってくる。エピローグは師匠がいないので、音楽はなし。任務2（ボーナスタイム）だけは、暗くクールな走る曲（テンポ128、D マイナー、16分で転がり続けるベース）に切りかわる。遊びが進むほど楽器が増えて盛り上がり（日報で「ポッ」のフレーズとアルペジオ、Seek でメロディ）、海外の銀行に入ると「ため」のあと「ドーン」とサビに入る。切りかわりはいつもループ（8小節）の終わりなので、曲が途中で崩れない。コマンドを打つと、リズムに合わせて「ビシュッ」と鳴る。練習（チュートリアル）は、日常的でちょっとかっこいいローファイ・グルーヴ（テンポ90、裏を大きくハネさせ、エレピの和音と丸いベース。練習は短いので、最初からドラムもメロディも入った「サビ」をループする。後半4小節ごとにビブラフォン風のメロディ）
- **画面**：ブラウン管風の走査線、文字が暗号から解読されていく表示、任務開始のカード、終了時に画面が消える演出
- **CASE FILE（右の欄）**：いちばん上に全体の目標「兄の死の真相に迫る」、その下に任務の目的、さらにその時々の小さな目標（例：人事DBに入る）が黄色の枠で出ます。目標ごとに、必要な手がかりが「◆ 見つけたもの／◇ ？？？」で並び、そろって条件を満たすと「OBJECTIVE CLEAR」→「NEXT OBJECTIVE」に進みます。本筋と関係の薄い手がかりは「？ 気になること」にまとまります（書き方は `src/scenario.js` の先頭の `objectives`）
- **EVIDENCE**：見つけた手がかりはカードで出て、「その目標の n / N」が分かります。任務完了の画面にも「回収 n/N」と出ます（`clue` を付けたものが手がかりになります）
- **任務2はボーナスタイム**：任務1で考えて疲れたあとなので、考えずに「ワンクリックでかっこいい演出を見て、サクサク楽しむ」任務。師匠が言った「次の一手」が NEXT 欄の先頭に光るボタン（▶）で出て、押すと入力欄にコマンドが入る（⏎ ボタンが光るので、Enter か ⏎ で実行）。ボタンの上には「なぜそれをやるのか」が、その場の基調の色の補色で出る。本文の説明や一覧は出さず、情報は師匠のセリフから拾う。システムに入るたびに画面の色合いが変わる（ファイル=水色、人事DB=ピンク、Seek=白青、財務会計=金、変更ログ=青緑）。サクサク進む部分は打つほど速くなり、見せ場はたっぷり時間をかけて派手に見せる：ファイルがあふれ出す → AIスキャン → 開かないフォルダとの攻防に負ける → 社長の写真／日報で権限を上げると世界が作り変わり、隠されたデータが赤く浮かぶ／人事DBで画面が裂けて一本の光に潰れ、弾むように組み直される → 画面が2つに割れて師匠の端末が見え、師匠が裏で LEVEL 5 の昇格を回し始め、ゲージが上がるほど画面が壊れていく（文字のちらつき・色ずれ・画面のあちこちが真っ暗に死んでいく・監査のログ）。その間にプレイヤーが自分で `ssh seek` を打つと、師匠が「……なるほどな」と昇格を止める／社内ネットワークを抜けて外の検索サイトへ／金庫のダイヤル → 伝票の滝 → 12億がメーターのように回る → 伝票のいちばん下の小さな「最終更新」に寄って、拡大して読む → 金の行き先を追う（子会社 → 実体のない会社 → 海外の銀行 → 「SRG」名義の口座で行き止まり）→ 世界地図の上を回線が走って、海の向こうの銀行に乗りこみ、口座を開く → 銀行に気づかれ、たどってきた経路を赤い光が日本へ向かって遡ってくる → 凍結までのカウントダウンと吸い出しの競争になり、凍結の 0.4 秒前にこっちが履歴を抜ききって、来た道の足跡を消して逆探知を断ち切る／社内の監視カメラを乗っ取り、左上から1台ずつ照合 → 非常階段Bで止まって「ブー」／消えかけた差分を、上書きされる前に復元（「千里眼」が画面いっぱいに浮かび上がる）
- **手がかり（EVIDENCE）**：カードが光って現れ、文字が解読されてから、少し間をおいて次へ進む（見つけた余韻を残す）
- **画面が裂ける演出**：衝撃や警報のときは、画面が横の帯ごとに裂けて、赤と青の色がずれる（SVG のフィルターをその場で動かしている）
- **return**：任務1・2では、目的を果たしても勝手には終わらない。師匠が「調べたいことは調べたな」と言ったあとも探索を続けられ、`return` と打つと `git commit -m "どう？楽しめた？"` と `git push` が自動で流れて完了画面へ
- **任務3の山場**：自分が打ったコマンドが「予測済」として流れ、マウスを追いかける目が開く → 赤い警報と逆探知 → 師匠が回線を奪い返して青に変わる
- **エピローグ**：ニュースが流れたあと、画面の文字が崩れていき、前触れなく真っ暗になって終わります

## ネタバレ対策

ビルドのとき、**任務のデータ全体をその回線コードで暗号化**しています（PBKDF2 ＋ AES-GCM。仕組みは NODE//ZERO と同じ）。
さらに、人事DB（パスワード）と照合システム（犯人のID）の中身は、その答えでもう一重暗号化しています。
公開データには、まだ受け取っていない任務の文章も、答えも入っていません。
