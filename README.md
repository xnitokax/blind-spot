## 演出

- **音**：Web Audio でその場で合成しています（音声ファイルなし）。ピコピコした音は使わず、低音・ノイズ・残響で映画の UI のような質感にしています
- **BGM**：相棒の師匠が「いい音楽かけといてやるよ」と流す、作業に集中できる落ち着いたロー・ファイ寄りの曲。これもその場で演奏しています。メロディは毎回その場で作るので、同じくり返しにならず、長く聞いても疲れにくい。ラジオのように開いて始まり、師匠がしゃべる間は少し下がる。任務3の警報でテープのように止まり、師匠が回線を奪い返すと戻ってくる。エピローグは師匠がいないので、音楽はなし。任務2だけは、暗くクールな走る曲（テンポ128、D マイナー、16分で転がり続けるベース）に切りかわる。遊びが進むほど楽器が増えて盛り上がり（日報で「ポッ」のフレーズとアルペジオ、Seek でメロディ）、海外の銀行に入ると「ため」のあと「ドーン」とサビに入る。切りかわりはいつもループ（8小節）の終わりなので、曲が途中で崩れない。コマンドを打つと、リズムに合わせて「ビシュッ」と鳴る。会話パート（師匠とのチャット・しおりと会う場面）は、探偵事務所の受付の曲：夜のジャズ・ラウンジ風（テンポ76のスウィング、Cm9 → Fm9 → Dm7♭5 → G7♭9、エレピ・歩くベース・ブラシ・8小節の後半にビブラフォン）。会話が終わると、ゆっくり消える。練習（チュートリアル）は、日常的でちょっとかっこいいローファイ・グルーヴ（テンポ90、裏を大きくハネさせ、エレピの和音と丸いベース。練習は短いので、最初からドラムもメロディも入った「サビ」をループする。後半4小節ごとにビブラフォン風のメロディ）
- **画面**：ブラウン管風の走査線、文字が暗号から解読されていく表示、任務開始のカード、終了時に画面が消える演出
- **CASE FILE（右の欄）**：いちばん上に全体の目標「兄の死の真相に迫る」、その下に任務の目的、さらにその時々の小さな目標（例：人事DBに入る）が黄色の枠で出ます。目標ごとに、必要な手がかりが「◆ 見つけたもの／◇ ？？？」で並び、そろって条件を満たすと「OBJECTIVE CLEAR」→「NEXT OBJECTIVE」に進みます。本筋と関係の薄い手がかりは「？ 気になること」にまとまります（書き方は `src/scenario.js` の先頭の `objectives`）
- **EVIDENCE**：見つけた手がかりはカードで出て、「その目標の n / N」が分かります。任務完了の画面にも「回収 n/N」と出ます（`clue` を付けたものが手がかりになります）
- **任務2は謎解き（任務1より難しい）**：社内のシステムが一通り開いていて、どこに何があるかは自分で探す。光るボタン（次の一手）は出さない。師匠は、間違えたときに少しだけ口を出す（例：財務会計で「裏金」と検索すると「数字を見ろ」、変更ログを日付だけで検索すると「もっと絞れ」）。その場所でだけ使えるコマンド（`scan` / `stat` / `trace --money` / `open --account` / `cam --live`）は `help` の「ここで使えるコマンド」に出る。違う番号や名前で打つと、ふつうの返事が返ってくる。目標は3つで、それぞれの手がかりがそろうと次へ進み、最後の目標の手がかり（5つ）がどの順番でもそろった時点で任務完了。システムに入るたびに画面の色合いが変わる（ファイル=水色、人事DB=ピンク、Seek=白青、財務会計=金、変更ログ=青緑）。解いたごほうびとして、見せ場はたっぷり時間をかけて派手に見せる：ファイルがあふれ出す → AIスキャン → 開かないフォルダとの攻防に負ける → 社長の写真／日報で権限を上げると世界が作り変わり、隠されたデータが赤く浮かぶ／人事DBで画面が裂けて一本の光に潰れ、弾むように組み直される → 画面が2つに割れて師匠の端末が見え、師匠が裏で LEVEL 5 の昇格を回し始め、ゲージが上がるほど画面が壊れていく。その間にプレイヤーが自分で `ssh seek` を打つと、師匠が「……なるほどな」と昇格を止める／社内ネットワークを抜けて外の検索サイトへ／金庫のダイヤル → 伝票の滝 → 12億がメーターのように回る → 「最終更新」に寄って、拡大して読む → 金の行き先を追う（子会社 → 実体のない会社 → 海外の銀行 → 「SRG」名義の口座で行き止まり）→ 世界地図の上を回線が走って、海の向こうの銀行に乗りこみ、口座を開く → 銀行に気づかれ、逆探知と凍結のカウントダウン → 凍結の 0.4 秒前に履歴を抜ききって、足跡を消す／社内の監視カメラを乗っ取り、1台ずつ照合 → 非常階段Bで止まって「ブー」／消えかけた差分を、上書きされる前に復元（「千里眼」が画面いっぱいに浮かび上がる）
- **手がかり（EVIDENCE）**：カードが光って現れ、文字が解読されてから、少し間をおいて次へ進む（見つけた余韻を残す）
- **画面が裂ける演出**：衝撃や警報のときは、画面が横の帯ごとに裂けて、赤と青の色がずれる（SVG のフィルターをその場で動かしている）
- **return**：任務1・2では、目的を果たしても勝手には終わらない。師匠が「調べたいことは調べたな」と言ったあとも探索を続けられ、`return` と打つと `git commit -m "どう？楽しめた？"` と `git push` が自動で流れて完了画面へ

## ネタバレ対策

ビルドのとき、**任務のデータ全体をその回線コードで暗号化**しています（PBKDF2 ＋ AES-GCM。仕組みは NODE//ZERO と同じ）。

公開データには、まだ受け取っていない任務の文章も、答えも入っていません。

## 開発

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

- ゲーム：http://localhost:8766/docs/
- ビルドせずに確認する（回線コードの一覧も出る）：http://localhost:8766/docs/?dev
- ビルド：http://localhost:8766/tools/build.html を開いて「ビルド」を押す → `docs/scenario.data.js` と `docs/scenario.more.js` が更新される（接続先の書き間違いや、回線コードの重複もチェックします）
  - `docs/index.html` が読み込む js・css にも、版の番号（`?v=年月日時分`）を付け直す。iPhone の Safari が古いファイルを使い回さないように、**js・css だけを直したときも、公開の前にビルドする**
  - 「体験版」にチェックが入っていると、公開データには `demo: true` の章（練習と任務1）だけが入り、ほかの章は `scenario.more.js` に分かれる。チェックを外すと、すべての章が公開データに入る（製品版）
