# BLIND//SPOT

マーダーミステリー「uzu」と行き来する、一人用シナリオの **Web 側（ハッキング画面）** の試作です。
▶ **遊ぶ**：https://xnitokax.github.io/blind-spot/ （回線コードは下の「回線コード」の表にあります）

設定は [設定メモ.md](設定メモ.md) が正です。未定のところは仮の内容で埋めて、最後まで筋が通るようにしています。
（`src/scenario.js` で「（仮）」を検索すると、あとで決めるところが見つかります）

## 遊び方

1. uzu 側で、師匠から **回線コード** を受け取る
2. Web 画面を開いて「CLICK TO CONNECT」を押す（ここから音が出る）
3. 初めてのときは、師匠に呼び名を聞かれる。`handle 名前` と打ち、確認に `y` で答える（コマンド入力のチュートリアルを兼ねる）
   決めた名前はプロンプト（`anonymous@safehouse:~$`）や師匠のセリフ、任務3の「予測ファイル　対象：〇〇」に使われる。2回目からは「おかえり」で始まる
4. `connect 回線コード` と打つ（`?line=回線コード` 付きの URL で開いた場合は、自動で打たれる）
5. 師匠が回線をつなぐ演出のあと、任務が始まる
6. 任務が終わると回線が切れる → uzu に戻って師匠に報告する

| コマンド | 使いどころ |
|---|---|
| `handle <名前>` | タイトル画面で、呼び名を決める・変える |
| `connect <回線コード>` | タイトル画面で、師匠から受け取った回線につなぐ |
| `ssh <名前>` | 接続先へ移動する |
| `back` | ひとつ前の場所へ戻る |
| `search <言葉>` | 日報・人事DB・伝票・変更ログなどを検索する。**上位3件しか表示されない**。スペース区切りで条件を重ねられる |
| `cd <フォルダ名>` | ファイルサーバーでフォルダを移動する |
| `return` | 調べ終わったら（任務1・2）、成果を持って帰る（任務を終える）。NEXT 欄の一番左に出る。早すぎると師匠に止められる |

パスワードやコードは、全角・半角、大文字・小文字を区別しません（全角の「！」で打っても通ります）。
検索は、さらにひらがな・カタカナと長音（ー）のあるなしも区別しません（「ゆーざーID」「ユーザID」でも見つかります）。「userid」「password」のような言いかえにも対応しています。
演出の途中は、画面をクリック（または Enter）すると早送りできます。右上の SOUND で音を全部、BGM で音楽だけを消せます。

## 演出

- **音**：Web Audio でその場で合成しています（音声ファイルなし）。ピコピコした音は使わず、低音・ノイズ・残響で映画の UI のような質感にしています
- **BGM**：相棒の師匠が「いい音楽かけといてやるよ」と流す、作業に集中できる落ち着いたロー・ファイ寄りの曲。これもその場で演奏しています。メロディは毎回その場で作るので、同じくり返しにならず、長く聞いても疲れにくい。ラジオのように開いて始まり、師匠がしゃべる間は少し下がる。任務3の警報でテープのように止まり、師匠が回線を奪い返すと戻ってくる。エピローグは師匠がいないので、音楽はなし
- **画面**：ブラウン管風の走査線、文字が暗号から解読されていく表示、任務開始のカード、終了時に画面が消える演出
- **CASE FILE（右の欄）**：いちばん上に全体の目標「兄の死の真相に迫る」、その下に任務の目的、さらにその時々の小さな目標（例：人事DBに入る）が黄色の枠で出ます。目標ごとに、必要な手がかりが「◆ 見つけたもの／◇ ？？？」で並び、そろって条件を満たすと「OBJECTIVE CLEAR」→「NEXT OBJECTIVE」に進みます。本筋と関係の薄い手がかりは「？ 気になること」にまとまります（書き方は `src/scenario.js` の先頭の `objectives`）
- **EVIDENCE**：見つけた手がかりはカードで出て、「その目標の n / N」が分かります。任務完了の画面にも「回収 n/N」と出ます（`clue` を付けたものが手がかりになります）
- **return**：任務1・2では、目的を果たしても勝手には終わらない。師匠が「調べたいことは調べたな」と言ったあとも探索を続けられ、`return` と打つと `git commit -m "どう？楽しめた？"` と `git push` が自動で流れて完了画面へ
- **任務3の山場**：自分が打ったコマンドが「予測済」として流れ、マウスを追いかける目が開く → 赤い警報と逆探知 → 師匠が回線を奪い返して青に変わる
- **エピローグ**：ニュースが流れたあと、画面の文字が崩れていき、前触れなく真っ暗になって終わります

## 回線コード（⚠️ ネタバレ）

| コード | 意味 | 内容 | 渡すタイミング（uzu 側） |
|---|---|---|---|
| `BLINK` | まばたき。のぞき見を始める | 任務1　社員名簿 | 導入のあと |
| `SQUINT` | 目を細める。裏を探る | 任務2　プロジェクト室 | 任務1の報告のあと |
| `STARE` | 見つめる。真相を直視する | 任務3　千里眼 | 任務2の報告のあと（死体の様子を師匠がまとめて見せる） |
| `BLIND` | 何も見えなくなる | エピローグ（数年後） | 最後の選択で「揉み消す」を選んだときだけ |

「見る」が任務ごとに強くなっていき、監視社会を選んだ人だけが最後に「見えなくなる」。

## 攻略の流れ（⚠️ ネタバレ）

- **任務1**：人事DBはユーザーIDとパスワードが必要 → 日報で `search ユーザーID`（石田の愚痴から、IDは「苗字.名前」）→ `search パスワード`（情シスの愚痴から、「大事な人の名前＋生年月日」が多い）→ `search 人事部` → 口の軽い朝比奈さんを `search 朝比奈` → ID は `asahina.satsuki`（ID が通ると、パスワードの文字数が出る）、娘の名前と誕生日、「私らしく」「3回目」から `hikari20200822!!!` → 人事DBで `search 真壁` → 兄は技術職で「特別プロジェクト室」にいた
- **任務2**：ファイルサーバーの名前のないフォルダは空 → 日報で `search プロジェクト室`（2件だけ、書いたのは室長）→ 室長の名前では出てこない → 人事DBでも「室長」としか書かれていない → 外の検索サイトで `search 鷲尾`（次期長官候補の官僚）→ 財務会計で `search 裏金`（兄が死んだ日の 02:47 に更新）→ 情シスの変更ログで `search 02:47` → 消された文言から、プロジェクト名「千里眼（SENRIGAN）」と政府の関与が分かる
- **任務3**：ファイルサーバーで `cd senrigan` → 関係者名簿を `search 左 18` などで絞り込む → 照合システムに `S-06` → 措置記録と危険度一覧 → 兄のプログラム `mm_zero` とメッセージ → 自分の行動予測 → 逆ハッキング → 師匠が身代わりに
- **エピローグ**：数年後、ニュースを見る → 記事が乗っ取られて終わる

隠し：人事部の黒田（`kuroda.seiichi` ／ パスワード `nitoka20030722`）と佐伯（`saeki.mayu` ／ パスワード `mayu20031225`）でもログインできる（ログイン名がその人になる）。

## ネタバレ対策

ビルドのとき、**任務のデータ全体をその回線コードで暗号化**しています（PBKDF2 ＋ AES-GCM。仕組みは NODE//ZERO と同じ）。
さらに、人事DB（パスワード）と照合システム（犯人のID）の中身は、その答えでもう一重暗号化しています。
公開データには、まだ受け取っていない任務の文章も、答えも入っていません。

## ファイル構成

```
設定メモ.md            シナリオの設定（正）
src/scenario.js        シナリオ本体（⚠️ ネタバレ。回線コードもパスワードも平文）
docs/                  公開されるファイル
  index.html           ゲームエンジンと画面
  nz-crypto.js         暗号化・復号（ビルドツールと共用）
  scenario.data.js     ビルドで生成したデータ（自動生成）
tools/
  serve.ps1            開発用ローカルサーバー（ポート 8766）
  build.html           ビルドツール
```

## 開発

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

- ゲーム：http://localhost:8766/docs/
- ビルドせずに確認する（回線コードの一覧も出る）：http://localhost:8766/docs/?dev
- ビルド：http://localhost:8766/tools/build.html を開いて「ビルド」を押す → `docs/scenario.data.js` が更新される（接続先の書き間違いや、回線コードの重複もチェックします）
